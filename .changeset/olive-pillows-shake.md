Support TypeScript design token files (`.ts`, `.mts`, `.cts`) as `source`/`include` files, as well as TypeScript config files, when running on a runtime that supports importing TypeScript natively, e.g. Node.js >= 22.18 (or >= 22.6 with `--experimental-strip-types`), Bun or Deno.
